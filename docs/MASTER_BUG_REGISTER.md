# Master Bug & Vulnerability Register
## Hiralal and Sons Sales Pvt. Ltd. — Platform Security & Reliability

This document serves as the single authoritative register of all security vulnerabilities, financial edge cases, business-logic defects, data-integrity issues, and infrastructure weaknesses discovered across all audit phases, along with their root causes, remediations, test references, and verified statuses.

### Status Dictionary
- `NEW`: Newly identified finding awaiting triage or reproduction.
- `CONFIRMED_UNFIXED`: Defect confirmed via code trace or test; fix pending.
- `IN_PROGRESS`: Remediation actively being implemented.
- `FIXED_PENDING_VERIFICATION`: Fix committed, awaiting independent test execution.
- `FIXED_VERIFIED`: Fix verified through observed passing tests, builds, and code review.
- `REGRESSION`: Previously resolved defect reopened due to regressions.
- `DUPLICATE`: Finding shares the exact root cause with another finding ID.
- `FALSE_POSITIVE_VERIFIED`: Hypothesis disproven; behavior is safe or defended by existing controls.
- `UNRESOLVED`: Known defect or architectural limitation requiring external integration or out-of-scope work.
- `BLOCKED`: Remediation blocked by missing third-party credentials or infrastructure dependency.
